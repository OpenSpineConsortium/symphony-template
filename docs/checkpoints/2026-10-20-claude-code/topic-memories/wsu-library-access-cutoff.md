Per https://guides.lib.wayne.edu/DMCWSU (updated 2026-06-30): Tenet Healthcare
decided WSU Libraries would stop providing library services to Tenet/DMC-sponsored
residents after **2026-06-30**. Residents are redirected to DMC Graduate Medical
Education, (313) 745-5146. A separate WSU appointment (faculty/staff, or a
WSU-sponsored rather than DMC-sponsored line) may still carry an AccessID -- check
before relying on it.

Also verified about WSU's own collection:
- **No print holding of *Spine*** in either the Alma/Primo or legacy catalog. The
  CONSER MARC 850 code `MiDW-M` is historical; the run was discarded.
- WSU's Ovid entitlement (LWW Total Access 2022) starts **1996, vol. 21**. Anything
  earlier is outside the subscription.
- ILLiad, if eligible: https://wayne.illiad.oclc.org/illiad/logon.html -
  wild@wayne.edu - 313-577-4011. Shiffman ILL 313-577-1100.

**How to apply:** don't assume a WSU route for older full text. For pre-1996 LWW
journals go to U-M (Journals@Ovid Complete runs to 1976 vol. 1) or print/microfiche.
See [[panjabi-1991-page-892]] for the case that established this.
