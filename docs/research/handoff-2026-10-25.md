## 3. What is tied to the old account

A claude.ai Project belongs to one account and cannot be shared (CLAUDE.md, Constraints). So the new account makes its own Project, and these stay with the old one:

- The Project's shared files (the folder every thread of "symphony3" reads): cv-out/, dataset-requests/, ip-review/, smoke/, storage/, textbook/ and uploads/. They are not in git. What a new thread needs from them it gets from git: smoke/ restates SchwingNet #252 and #253, storage/ the spine-datasets chooser and audit (SchwingNet #292, spine-datasets #250), dataset-requests/ the NIA Biobank request (nia-aging-research-biobank-requests.md here). ip-review/ is the owner's private analysis and is not to be copied into any repository; cv-out/ is career material and stays out of git.
- The textbook reader, https://claude.ai/artifact/Roz1iKJfgPVSTsSNd2iw9m, published 2026-10-25 about 09:30 UTC (SchwingNet #294, #295). It reads the book from the old Project's files (textbook/CURRENT.json, book-<sha12>.json and .bin) with the viewer's own access, so it opens only for a member of the old Project. For the new account: a thread of the new Project stages the book into the new Project's files with `python3 tools/textbook_reader.py stage --clone <a clone>` (SchwingNet), and the owner republishes the reader from the owner's computer with `python -X utf8 tools/textbook_publish.py local`, Claude Code signed in as the new account (`/status` shows the account, `/login` switches), after the reader's `files` capability names the new Project's id. That is a change to SchwingNet's tools/textbook_reader.html and the publish record on the branch textbook-artifact, one pull request in SchwingNet. Until then the old account's link keeps working for the old account.
- The old Project's thread history and its private memory. The project's shared memory is in git (docs/memory/ in each repository), and the facts below in section 7 are the ones the old Project's own memory held that every thread used.

What carries over without any step: the repositories, their issues and boards, the grid and its gate words, the GitHub Apps and the Actions secrets, since none of them belong to a Claude account.
