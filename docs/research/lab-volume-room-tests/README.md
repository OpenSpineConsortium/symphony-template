# Tests behind the lab volume's room

Source: the thread "Paired CT and X-ray datasets", 2026-10-23 and 2026-10-24, saved from the cloud session's scratch folder when the owner asked every thread to stop and hand off (06:14 UTC). These are the harnesses behind the figures in lab-volume-room.md and in the bodies of SchwingNet #181 and #191; they were run against a copy of SchwingNet's worktree, so each names paths in that session's scratch folder, which no later session has. Read them as a record of what was tried; to run one again, point its paths at a fresh SchwingNet clone at the commit named below.

- review/: the second reviewer's reproductions for SchwingNet #191, run against the worktree at 6a9db11: grid_sim.py builds the grid's layout (the mount's root two levels above the 40 TiB group, the subvolume's folder with .meta, a volume whose own rbytes reads as 48 digits), e2e.py runs the readout and the fetch job on it, c.py moves a set between two readings. Their results are findings 1 to 5 of #191's "Adversarial review".
- mutation-190/: the mutation round for SchwingNet #190 (#191): mutations.txt lists each mutant of grid/size-rule.sh as a line to change, run.py and run.sh apply one at a time and run tests/test_xray_chain.py, grid-layout-test.py is the extra test of the grid's layout, a method kept at its indentation to paste into the test class of tests/test_xray_chain.py, so it does not compile on its own. #191's body gives the counts (24 mutants; the first round left four alive, which 6f99953's tests kill).
- mutation-180-181/: the mutation rounds for SchwingNet #180 and #181, the same method on the change each made.

The raw outputs of the runs and the copies of size-rule.sh they mutated are not kept here, as .claude/rules/research.md asks; the figures above are in the pull requests' bodies.
