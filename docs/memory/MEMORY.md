# Memory index

One line per fact under docs/memory/: a dash, the fact's title as a link to its file, a colon and one line saying what it is. CLAUDE.md imports this file into every session; a fact's own file is read when its line says it matters. Add or correct a fact with the remember skill (.claude/skills/remember): one file, one line here, in the same pull request as the change it came from. This index stays under 200 lines and 25 KB, a limit of this project's own: an imported file loads whole into every session's context, and Claude Code's guidance for an instruction file is under 200 lines. `scripts/check.sh` fails when a fact is missing here or a line names a file that is not there.

- [A copy runs the template's tests](a-copy-runs-the-templates-tests.md): every copy's required check runs the template's tests over the filled files, sharing perhaps off; tests/test_filled_copy.py runs a filled copy's check, sharing on and off and in crowd mode, so a test that holds only in the template fails there first.
- [A Project with several repositories runs no hooks](a-project-with-several-repositories-runs-no-hooks.md): GitHub's ruleset, the claim lock, the required check, /board and the claim skill still hold; the push guard, the board at session start and the Symphony-Usage trailer do not, so keep one repository per Project.
- [A template copies no settings](a-template-copies-no-settings.md): what "Use this template" leaves to the owner (one run of scripts/setup-repo.sh, the token from claude setup-token, or scripts/crowd.py setup for a crowd repository) and what an organization on Team or above can set once for every repository it makes.
- [CI runs Python 3.12](ci-python-is-3-12.md): the checks run on GitHub's 3.12, so tools and tests use no API newer than that; test with python3.12 where it exists.
- [Claim branches push by name](claim-branches-push-by-name.md): a claim branch is made with --no-track, a clone made for one branch is told to fetch every branch, every push names its branch and the lease the tip pushed, since git's push.default, a single-branch clone and a lease after a fetch each sent a push somewhere the push guard cannot see.
