# Memory index

One line per fact under docs/memory/: a dash, the fact's title as a link to its file, a colon and one line saying what it is. CLAUDE.md imports this file into every session; a fact's own file is read when its line says it matters. Add or correct a fact with the remember skill (.claude/skills/remember): one file, one line here, in the same pull request as the change it came from. This index stays under 200 lines and 25 KB, a limit of this project's own: an imported file loads whole into every session's context, and Claude Code's guidance for an instruction file is under 200 lines. `scripts/check.sh` fails when a fact is missing here or a line names a file that is not there.

- [A template copies no settings](a-template-copies-no-settings.md): what "Use this template" leaves to the owner (one run of scripts/setup-repo.sh, the token from claude setup-token, or scripts/crowd.py setup for a crowd repository) and what an organization on Team or above can set once for every repository it makes.
- [CI runs Python 3.12](ci-python-is-3-12.md): the checks run on GitHub's 3.12, so tools and tests use no API newer than that; test with python3.12 where it exists.
- [@claude runs on the main account's subscription](claude-mentions-run-on-the-main-accounts-subscription.md): mentions run .github/workflows/claude.yml on the token from `claude setup-token`, spending plan limits, never an API key; in crowd mode it never runs.
- [Code owners are users or teams](code-owners-are-users-or-teams.md): GitHub never asks an organization for review, so template-init writes the owner, or in an organization's copy the person who made it, into .github/CODEOWNERS; check with the codeowners/errors API.
- [Crowd mode](crowd-mode.md): scripts/crowd.py sets a repository up for volunteers on their own Claude accounts; the variable CLAUDE_CROWD, the required check's crowd guard and queue.yml then keep the Claude workflows off, Claude secrets out, checkpoints out of commits and the queue to maintainers.
- [Field metrics](field-metrics.md): .github/workflows/metrics.yml writes aggregates only (no name, title or text) to the branch metrics with GITHUB_TOKEN; a maintainer's own claude -p adds App F counts; a breakdown by work setting (one person's several sessions apart from several people) and in pairs; the switch is .github/symphony-metrics or SDLC_METRICS=off; the release marker and the board's words it counts.
- [How this repository works](how-this-repository-works.md): the repository is the shared plane for every Claude account and session; what lives where.
- [Protocol changes come from symphony-protocol](protocol-changes-come-from-symphony-protocol.md): the claim protocol is changed in OpenSpineConsortium/symphony-protocol, whose sync pull request `symphony-protocol/sync` brings it to OpenSpineConsortium/symphony-template, while a repository made from the template vendors it by hand with `--consumer OpenSpineConsortium/symphony-template`; never edit tools/sdlc_protocol, which scripts/check.sh holds to the hashes in tools/VENDORED and CI to the library's own files.
- [Team mode](team-mode.md): a lead plans an epic into pre-assigned tasks, members work them in parallel and land by auto-merge; the lead integrates; switched on by CLAUDE_TEAM with CLAUDE_WORKER.
- [The front door is one press](the-front-door-is-one-press.md): install the App, press Create on the form its Setup URL opens, merge; the run picks the repository by id, reads the kind from the tree and shares aggregates unless a box says otherwise; the sweep is the fallback.
- [The plan ladder](the-plan-ladder.md): which GitHub and Claude plans unlock what, verified 2026-10-09; public repo means free Actions and enforced protection, no payment method means a hard cap.
