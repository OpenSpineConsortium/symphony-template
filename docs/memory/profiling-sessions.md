Profiling a session: tools/profile.py reads a session's transcript, the same file tools/usage.py reads for the usage trailer, and gives what the session spent as counts alone, for the research programme under docs/research/beyond-cooperation/.

A Claude Code transcript carries the API's own token counts on every call and every tool call with its answer, so what a session spent on context, tool calls, reading and time can be measured afterwards by code, from the file, with nothing installed and nothing sent anywhere. `python3 tools/profile.py TRANSCRIPT --json FILE` writes the record and prints the report: each API call once by its message id, the context call by call with its cached share and compactions, calls by tool with their failures, bytes and seconds, reads and re-reads of files, and seconds in tools against seconds waiting for the model. The record never carries a path, a command, a prompt or any text, so it can be committed beside the question it answers; tests/test_profile.py is the definition of every count.

The programme measures a way of working before changing it: context compression, fewer tool calls and less code reading are its arms, each read beside whether the work landed, and no run that spends tokens starts without the owner's word and the number. The first record is docs/research/beyond-cooperation/baseline-2026-10-15.json, the thread that wrote the instrument; its first API call carried 120,867 tokens before any work, the instructions and memory every session of this project starts with.
